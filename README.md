# Pirandello Rooms - Sito vetrina

Sito vetrina statico per il B&B Pirandello Rooms.

## Contenuto incluso

- Home con hero section professionale
- Sezione chi siamo e punti di forza
- Sezione camere con 6 card geometriche e uniformi
- Ogni camera include:
- prezzo per notte
- descrizione
- caratteristiche principali
- galleria foto scorrevole (slider)
- Sezione contatti
- Layout responsive per desktop e mobile

## File principali

- index.html
- styles.css
- script.js
- assets/camere/
- assets/camere/camera-01 ... camera-06

## Come aprire il sito

Apri index.html nel browser.

## Personalizzazione futura

Quando avrai i dati ufficiali, aggiorneremo:

- testi e tone of voice
- prezzi definitivi
- caratteristiche reali delle camere
- immagini ufficiali
- contatti e link prenotazione

## Gestione immagini locali delle camere

Le immagini sono caricate direttamente da cartelle locali.

Struttura:

- assets/camere/
  - camera-01/
  - camera-02/
  - camera-03/
  - camera-04/
  - camera-05/
  - camera-06/

Nomi file consigliati in ogni cartella camera:

- foto-1.jpg
- foto-2.jpg
- foto-3.jpg
- foto-4.jpg

Se un file manca, il sito mostra automaticamente un'immagine segnaposto elegante.
